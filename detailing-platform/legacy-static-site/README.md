# Dark Side Car's — сайт-приложение (PWA)

Одностраничный сайт студии детейлинга, который устанавливается на домашний экран
телефона и открывается как обычное приложение — без адресной строки браузера.

---

## Что внутри

```
index.html              главная страница, весь CSS и JS внутри файла
portfolio.html          галерея работ с фильтрами и просмотром
manifest.webmanifest    описание приложения: имя, иконки, ярлыки
sw.js                   service worker — оффлайн-режим и кэш
icons/                  иконки всех размеров, включая maskable и apple-touch
make_icons.py           скрипт, которым сгенерированы иконки
README.md               этот файл
```

Зависимостей нет, сборка не нужна. Файлы работают как есть.

---

## Как опубликовать

### GitHub Pages

1. Создайте репозиторий и загрузите в него все файлы (сохраняя папку `icons/`).
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

Пути в проекте относительные, поэтому сайт работает и в подпапке, и на своём домене.

**HTTPS обязателен.** Service worker и установка на домашний экран не работают по
обычному `http://` и не работают при открытии файла двойным щелчком (`file://`).
GitHub Pages выдаёт HTTPS сам. Для локальной проверки запустите из папки проекта:

```bash
python3 -m http.server 8000
```

и откройте `http://localhost:8000` — `localhost` считается доверенным адресом.

## Как поставить приложение на телефон

### Android (Chrome)
Внизу экрана появится плашка «Установите приложение» → **Добавить**.
Если плашку закрыли — меню браузера (⋮) → **Установить приложение**.

### iPhone (Safari)
Safari не показывает кнопку установки — на iOS это делается вручную:
кнопка **«Поделиться»** (квадрат со стрелкой вверх) → **«На экран „Домой“»** → **«Добавить»**.
На сайте есть подсказка с этими шагами: она появляется на iPhone через пару секунд.

### Что даёт установка
- Иконка рядом с обычными приложениями, запуск без адресной строки.
- Долгое нажатие на иконку открывает ярлыки: «Запись», «Работы», «Контакты».
- Сайт открывается даже без интернета — из кэша.

**Про уведомления.** Push-уведомления в проект не заложены. На iPhone они в принципе
не работают для сайта, открытого обычной вкладкой, — только после установки на
домашний экран. Обещать их клиенту без отдельной серверной части нельзя.

## Что нужно заменить перед показом владельцу

### 1. Фотографии — главное

Сейчас на месте снимков стоят аккуратные заглушки. Реальных фото у студии
больше 500 штук в карточках Яндекс Карт и 2ГИС, но взять их оттуда нельзя —
права на них у студии и авторов. Попросите у владельца исходники.

**Главная страница, блок «До и после»** — найдите в `index.html` блок
`<div class="ba" id="ba">` и замените каждый `<svg>` на:

```html
<img src="works/do.jpg" alt="Кузов до полировки" style="width:100%;height:100%;object-fit:cover">
```

**Блок «Портфолио» на главной** — шесть элементов `<div class="shot">`,
внутри каждого так же меняется `<svg>` на `<img>`.

**Страница portfolio.html** — здесь проще всего: в начале скрипта есть массив
`ITEMS`, каждая строка описывает одну работу:

```js
{c:"film", t:"Оклейка капота и бампера", s:"Защита зон риска"},
```

Добавьте в объект поле с путём к фото и подставьте его в функцию `art()`
вместо рисунка-заглушки, либо замените функцию на возврат тега `<img>`.
Категории уже готовы: `film`, `tint`, `polish`, `ceramic`, `clean`, `chrome`.

Фотографии кладите в папку `works/` и сжимайте до ширины ~1600 px —
иначе страница будет долго открываться на мобильном интернете.

### 2. Иконка приложения

Сейчас это оригинальный знак — тёмная сфера с янтарным бликом. Логотип студии
в него не заложен. Если у владельца есть свой логотип, замените файлы в `icons/`,
сохранив имена и размеры. Важно: `maskable-*.png` должны иметь запас по краям
около 20% — Android обрезает иконку под форму своей темы.

### 3. Мессенджеры

WhatsApp и Telegram подтверждены только для одного номера — **+7 (988) 028-33-48**.
Он подставлен для обоих филиалов. Если у волгоградского адреса свой WhatsApp,
поправьте константы в начале скрипта `index.html`:

```js
var WA = "https://wa.me/79880283348";
var TG = "https://t.me/+79880283348";
```

Telegram-ссылка сейчас ведёт по номеру и текст сообщения не принимает —
при нажатии текст копируется в буфер обмена. Если у студии есть обычный
username (вида `t.me/darksidecars`), замените ссылку на
`https://t.me/darksidecars` — тогда всё будет работать так же, как WhatsApp.

### 4. График работы

Подтверждено только открытие волжского филиала в 9:00 — оно и указано.
График волгоградского филиала найти не удалось, поэтому его на сайте нет.
Уточните у владельца и добавьте в блок «Контакты».

### 5. Цены

Цен на сайте нет намеренно. В карточке Яндекса прайс есть, но помечен как
давно не обновлявшийся — показывать такие цифры клиенту нельзя.
Когда владелец даст актуальный прайс, его можно добавить отдельным блоком.

## Что на сайте есть

**Первый экран** — заголовок, предложение, три кнопки: позвонить, написать, заказать.
Награды и рейтинг вынесены наверх.

**Переключатель филиалов в шапке** — меняет телефон, ссылку на маршрут и награду
по всему сайту сразу. Выбор запоминается: при следующем заходе откроется тот же филиал.

**Услуги** — шесть карточек, только подтверждённые направления.

**Доверие** — рейтинг 5,0, число оценок и отзывов, и разбивка по темам
(персонал 98%, время ожидания 98%, тюнинг 95%, тонировка 94% и далее).
Это фактические данные из карточки Яндекс Карт на 30 сентября 2026 года.
Тексты отзывов не скопированы — вместо них ссылка на карточку, где их можно прочитать.

**До и после** — сравнение перетаскиванием ползунка, работает и мышью, и пальцем.

**Портфолио** — шесть работ на главной и отдельная страница с фильтрами
по шести категориям, просмотром крупно, стрелками и свайпом.

**Процесс** — четыре шага от заявки до приёмки.

**Подбор услуги** — отмечаете услуги, объём, филиал, вводите машину и телефон;
внизу собирается готовое сообщение, кнопка открывает WhatsApp с уже вписанным текстом.
Ничего не отправляется само — человек сам решает, нажимать ли «отправить».

**FAQ, контакты обоих филиалов, ссылки на соцсети.**

**Нижняя панель на мобильном** — Позвонить, WhatsApp, Маршрут; всегда на экране.

## Проверено

- Ширины 320, 360, 390, 430, 768, 1024, 1440 px — горизонтального скролла нет,
  заголовки не обрезаются, кнопки не вылезают за край.
- Установка, оффлайн-режим и кэш — service worker активен, 11 файлов в кэше,
  страница открывается при выключенной сети.
- Манифест: `id`, `start_url`, `scope`, иконки `any` и `maskable`, три ярлыка.
- Ошибок в консоли нет.
- Сайт читается и с выключенным JavaScript: видны все тексты, телефоны,
  адреса и FAQ. Не работают только фильтры, ползунок и конструктор заявки —
  вместо него остаются прямые ссылки на звонок и мессенджеры.

## Не проверено

Standalone-режим на живых iPhone и Android — под рукой не было устройств.
Перед сдачей откройте сайт на телефоне, поставьте на домашний экран и убедитесь,
что приложение стартует без адресной строки.

## Обновление сайта

После правок поднимите версию кэша в `sw.js`, иначе у тех, кто уже открывал
сайт, останется старая копия:

```js
var VERSION = "dsc-v2";   // было dsc-v1
```

Старые кэши удалятся сами при следующем открытии.
